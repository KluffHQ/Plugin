# Kluff for Cursor

Kluff is a collaborative workspace where teams and AI agents work from the same company memory. This plugin connects Cursor to your Kluff workspace through Kluff's hosted MCP server.

## What you can do

- List your projects and read their details
- Search everything you can access in the workspace: threads, messages and people
- Search what Kluff remembers for a project (facts, entities and history)
- See your agents, whether they're running, idle or waiting on you, and read their messages and the steps of each run
- Create an agent in a project, give it work, and stop a run

## Setup

1. Install the plugin from the Cursor Marketplace.
2. Cursor connects to `https://mcp.kluff.com/v1` and opens the Kluff sign-in page.
3. Sign in, choose a workspace and allow access.

Cursor can only see what you can see in that workspace, and anything it sends appears under your name. Approving your agents' actions and answering their questions is a separate permission that is off by default.

## Disconnect

In Kluff, open **Settings > MCP connections** and disconnect Cursor. Access ends immediately.

## Requirements

A Kluff account and membership of a Kluff workspace. Sign up at [kluff.com](https://kluff.com).
